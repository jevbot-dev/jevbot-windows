# Jevbot for Windows

**把你想完成的事，交给 Windows 上的 AI 助手。**

Jevbot 让你用自然语言操作应用。围绕一个应用创建任务，或让多个应用协作完成一件事：描述目标，选择需要的应用，查看执行过程，并在需要时补充要求或批准操作。

[下载 Windows 版](https://github.com/jevbot-dev/jevbot-windows/releases) · [关注更新](https://x.com/jevbot_dev) · [Mac 版](https://github.com/jevbot-dev/jevbot-mac)

## 从一句话开始

- “看看这个聊天窗口，整理对方的诉求，并给我几个回复建议。”
- “读取这份飞书文档，整理重点，再按我的要求更新内容。”
- “打开记事本演示这份流程，用 Recordly 录制窗口，完成后添加旁白和字幕。”

具体能完成的操作取决于已连接应用的能力和当前状态。打开相关应用、准备好项目，再把目标告诉 Jevbot。教程录制需要另外安装 Recordly；飞书云端操作需要配置官方 CLI。

## 一个任务，多个应用

在「自动化」中描述最终目标，Jevbot 协调所需应用的操作，并将步骤、结果和上下文保存在同一个任务中，便于继续处理。

输入 `@` 选择应用，让任务明确知道要使用谁。任务进行中可以继续补充要求，或从历史任务继续。

## 过程看得见，控制在你手里

- 查看任务进度、应用操作和执行结果。
- 对需要批准的操作进行确认，随时停止任务。
- 在执行过程中追加要求，调整后续步骤。
- 聊天副驾提供分析和候选回复，点击即可填入输入框；消息发送由你完成。

## 开始使用

**Windows 11，或 Windows 10 2004（19041）及以上 · x64 / ARM64**

1. 从 [GitHub Releases](https://github.com/jevbot-dev/jevbot-windows/releases) 获取对应架构的下载包，解压后运行 `Jevbot.exe`。
2. 在设置中配置可用的 AI 引擎。Agent 支持 Claude Code、Codex 和 DeepSeek Harness；聊天判断与回复建议使用 TypeSafe 和 DeepSeek，需要配置相应密钥。
3. 在设置中启用希望使用的应用，并按需配置 MCP 服务或应用连接。
4. 打开相关应用和项目，点击「新任务」，或进入「自动化」，输入你的目标。

安装包发布后，可在 GitHub Releases 下载。部分应用的画面读取需要安装 Windows 简体中文 OCR 功能，可在「设置 › 时间和语言 › 语言和区域」中添加。

## 面向日常工作，也面向内容创作

Jevbot 将应用操作组织成可以持续对话的任务，适合聊天辅助、文档整理、演示录制和重复的桌面操作。你提出目标，Jevbot 调用已连接应用的能力执行，你可以随时查看和调整。
